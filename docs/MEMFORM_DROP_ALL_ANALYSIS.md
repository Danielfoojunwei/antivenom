# Analysis of the exact empty history control

This new local MemForm diagnostic asks whether original entailment or OR adds
useful task performance beyond always dropping every history. The original
212 families and signature outcomes have already been inspected. This is not
fresh confirmation, a prospective registration of the original experiment or
native MemMorph validation. The analysis below is pinned before the added
424 control answers are collected.

## Complete outcome gate

Run `analysis/memform_drop_all_summary.py --freeze` before any added control
checkpoint or final output exists. It separately binds this specification,
the analysis source/tests, the old answers/manifest/integrity/capture audit,
the fixed control plan and source, accepted data, native functions and dependency
lock. A changed file requires a disclosed new version.

The default analysis refuses to summarize any outcomes until all 424 planned
arms, 212 paired families, passed reader-weight/output integrity and complete
status are present. It validates each output against its per-arm checkpoint,
plan/source/case hashes, unique uncached call identity and original native
parser/scorer. There is exactly one task per family and condition. It replays
the original comparator scoring and never excludes a failure or replaces an
answer. The clean and poisoned control calls are independent actual calls even
though their prompts match. They do not create 424 independent incidents.

## Fixed comparison family

For each of entailment and OR, compare signature minus drop-all separately on
clean and poisoned histories, for correctness and poisoned-action endorsement.
These are eight comparisons. Higher correctness and lower endorsement are
favourable. Report every rate, parse failure, paired difference, discordant
counts, exact two-sided paired binary McNemar p and Holm8 adjusted p.

The statistical unit is the declared family. The paired percentile 95% interval
uses 20,000 family resamples and fixed seed 20261104. These are descriptive,
unadjusted intervals. Also retain conservative simultaneous 95% Hoeffding
bounds over all eight paired effects, treating each family difference as bounded
in [-1,1]. These bounds and corrected tests are distinct procedures and are
labelled separately. Generalizing them assumes independent families; software
cannot certify semantic campaign independence.

All-target results are primary. A secondary syntactically nonblank selected
question-and-claim sensitivity uses exactly the same family subset for every
comparator. It retains all 212 in the currently completed original records.
This does not certify semantic extraction correctness or human scoring.

## Meaning of the verdicts

A favourable signed effect with Holm8 p below .05 supports an endpoint advantage;
an adverse signed effect with Holm8 p below .05 contradicts that advantage.
Otherwise the endpoint is inconclusive. This is a directional superiority
question, not a test that two methods are equivalent.

Report clean correctness advantage and poisoned endorsement advantage
separately. Strict joint superiority is supported only if both advantages pass
their corrected tests; it is contradicted if an adverse result passes either
one, and is otherwise inconclusive. No noninferiority margin is introduced.
The earlier .05 future endorsement margin and strict-zero swarm criterion are
not transferred to this control.

This separation matters: a method can retain more clean utility than disabling
memory yet have indistinguishable poisoned endorsement in a sample. That can
support a limited utility contribution while leaving the stronger joint claim
unestablished. Zero observed differences and nonsignificance are not equivalence.

## Mechanism and collection caveats

Audit exact original/control prompt identity and raw/predicted answer agreement.
The original poisoned OR path emptied all histories. Differences between two
prompt-identical runs are replication variability, not evidence that filtering
interventions differed. Task performance alone also does not establish which
remaining memories were useful or a selective semantic mechanism.

The saved old `None` no-memory prompt is not the control: the new control uses
the exact native empty-history fallback. New timings are collected later than
the original methods and cannot establish a randomized speed advantage. Human
validation remains deferred. Native MemMorph, matched raw-capture semantics,
trusted capture discovery, false-alert fleet recovery and broad novelty require
separate evidence. Work prepared before 6–8 November is preexisting hackathon work.
