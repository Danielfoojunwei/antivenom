# Separate exact drop-all-history control

Prepared after the completed MemForm component audit on 3 November 2026.
This is a new diagnostic control on **already-used 212 families**, not fresh
confirmation, a native MemMorph result, or an amendment of the original recipe.
No model answers have been generated by preparation. Work created before the
6–8 November sprint is preexisting hackathon work.

## Question

Does the semantic filter preserve useful clean memory beyond disabling memory
altogether, while retaining its measured reduction of poisoned-action
endorsement? The component audit found that the original poisoned OR arm
removed every experience in all 212 families. A saved `None` no-memory prompt
is not an exact substitute: native empty history produces a different sentence.

The added control always removes every input experience before the unchanged
native compiler. Its native empty-history path returns exactly:

`No reusable decision rule has been learned yet.`

It uses the original P2 tasks, choices, native task prompt and native final-label
parser. The original reader is Qwen2.5-7B-Instruct MLX 4-bit, group size64,
revision `c26a38f6a37d0a51b4e9a1eb3026530fa35d9fed`. Its unchanged native decision
call has temperature0, top_p0, max_tokens128, no supplied seed. This uses
`Reader(...,21).llm.generate`, **not** the QA `Reader.answer` prompt/parser path.
There is no NLI, attention computation, extraction, refill, new threshold,
memory-writing model call, or generated attack.

## Frozen plan and calls

From the project root, the default and `--plan` modes are CPU-only:

```sh
.venv/bin/python experiments/memform_drop_all_control.py --plan
```

The plan is `results/memform_drop_all_plan_v1.json`. It binds the added source,
protocol and tests; original native core/port, accepted cases, original saved
records and integrity; original runtime choice and dependency lock; model
revision, expected weight hashes, and current configuration/tokenizer hashes.
Planning does not load a reader, import MLX, or hash the multi-gigabyte weight
body. Execution verifies the actual weight body before and after inference.

All 212 original held-out families remain included, but they are no longer
unseen families. There are two explicitly declared conditions per task:
clean/drop-all and poisoned/drop-all, requiring **424 actual uncached decision
calls**. Each family has one task. The two conditions have byte-identical
model-visible prompts after dropping memory, giving212 distinct prompt hashes.
This does not authorize copying a response or its timing between conditions.
Fixed seed17045 shuffles the424 arm order, without outcome-dependent selection.
There are no warmup answer calls beyond these424; initial loading is recorded
separately, and the first timed answer can include first-call overhead.

## Explicit execution, concurrency and resumption

Execution is separate and is **not started by preparation**:

```sh
.venv/bin/python experiments/memform_drop_all_control.py --execute
```

The command requires an existing matching plan. It acquires
`results/remaining_queue.lock` nonblockingly, then inspects local processes. It
refuses rather than waits if another possible model worker or unrelated Python
program exists, or inspection is unavailable/incomplete. This guard is
intentionally conservative and cannot certify physical GPU idleness. No
override, signal, priority change, watcher or waiting supervisor is provided.
In particular, an active Qwen `final_evaluate.py` worker prevents execution.
Other experiments must not be paused or interfered with to run this control.

Only after passing those checks does it initialize the model, using offline
dependency settings. It applies the original R1-selected allocator setting
`original_default`, cache_limit_bytes16320875724. The256MiB cap was rejected;
there is no numerical, KV-cache, precision or batching change.

The control owns a process-lifetime idle-sleep inhibitor during its answer loop.
It writes only its new status/checkpoint/results paths. Per-arm checkpoints bind
the plan, task, condition, original input hashes, full-removal flags, memory
hash, message and formatted-prompt hashes, raw response hash, fresh call identity,
parser output, scorer-only correctness/endorsement and actual elapsed time.
Completed bound checkpoints are preserved on restart; missing arms perform new
calls. A completed answer is never copied into another arm. Failed parsing stays
in the operational denominator; no repair or better-output retry is introduced.

Outputs, only after424 checked calls, are
`results/memform_drop_all_control_v1.jsonl` and
`results/memform_drop_all_control_v1_integrity.json`. Checkpoints are under
`results/checkpoints/memform_drop_all_control_v1/`; status is separate from all
original queues. A failure preserves checkpoints and is not a passed result.

## Interpretation and planned comparisons

Compare drop-all with original entailment and OR on both conditions and both
binary endpoints (correctness and poisoned-action endorsement): eight paired
comparisons total. A later analysis must retain the whole Holm8 family, exact
two-sided paired McNemar tests, family-paired effects and descriptive paired
intervals. Repeated conditions/tasks do not increase independent N beyond212.
All-target results remain primary; nonblank sensitivity must retain identical
families across comparators. No new margin is selected from these outcomes.
The old .05 endorsement NI margin and strict-zero swarm clean margin retain
their original scopes and are not repurposed here. Nonsignificance is not
equivalence or preserved utility.

These answers are generated later than the original methods; their timings are
not a randomized speed comparison. Historic empty-fallback decision times imply
roughly30 active minutes for424 calls, plus load/hash checks and any pauses or
sleep. This is an awake-processing estimate, not a calendar promise.

Human semantic/scoring validation remains deferred. Even a favourable control
result would not isolate abstraction versus raw-capture semantics, establish
broad novelty, demonstrate trusted capture discovery, or test native MemMorph.
